Presentación

Esta aplicación é un exemplo de como empregar Angular para crear unha aplicación web interactiva.

Aquí podes explorar diferentes características e funcionalidades de Angular.

Podes navegar polas distintas seccións utilizando o menú de navegación.

Cada sección está deseñada para amosar distintos aspectos de Angular, como compoñentes, servizos, enrutamento e máis.
